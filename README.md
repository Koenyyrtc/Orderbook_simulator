# Limit Order Book in C++: a teaching project

> **AI-generated content.** The tutorial (PDF) was generated by an AI.
 Treat it as educational material, not as production software or financial advice.

## What this is

A small, self-contained C++17 project that shows how a limit order book works and how to build
one, together with a simulated market to exercise it. It is written for readers who are
comfortable with code, data structures and systems and have a basic grasp of finance, but are
new to C++.

It contains:

- **An order book** with price-time priority: limit, market, IOC, fill-or-kill and post-only
  orders, cancel, modify, and self-trade prevention.
- **An engine** in front of the book: id allocation, size and price-band risk checks, ownership
  checks and market statistics.
- **A discrete-event market simulator** with four kinds of simulated participants (market
  maker, noise trader, momentum trader, informed trader), per-agent latency, a hidden "true
  value" and CSV output.
- **A second, faster book** built on flat arrays and a pooled order store, plus a benchmark that
  compares it with the first.
- **Tests**: unit tests, randomised invariant checks, a differential test between the two
  books, and a simulator determinism test.

## Build and run

Requires a C++17 compiler (developed with g++ 13). No external dependencies.

```bash
g++ -std=c++17 -O2 -Wall -Wextra -o tests tests.cpp && ./tests     # run the tests
g++ -std=c++17 -O2 -Wall -Wextra -o sim main.cpp
./sim 42                  # one simulated minute; writes trades.csv and quotes.csv
./sim sweep 100           # average over 100 random seeds
g++ -std=c++17 -O2 -Wall -Wextra -o bench bench.cpp && ./bench     # benchmark
```

Runs are deterministic: the same seed always produces the same market.

## What it is not

This is a learning project, and it has real limits. The main ones:

- It is a **single-symbol, single-threaded** matcher with no persistence, authentication,
  clearing or settlement, and no auctions, halts or stop orders.
- The simulated market is a **simple model**. Agents have fixed rules, market data arrives with
  no delay, and there are no fees. Its results are qualitatively sensible but must not be used
  to estimate real profits, risk or market impact.
- The flat-array book is a benchmark vehicle. It has no self-trade prevention, fill-or-kill,
  post-only or modify, expects a bounded price range, and can be crashed by untrusted order ids.
- Benchmark numbers were measured on a shared cloud machine. Trust the ratios between the two
  books, not the absolute nanoseconds.

The accompanying tutorial discusses these limits, how to fix them and how venues defend
against abuse.
